      Cortex

      A shared memory that a team of AI agents reads, writes and is held accountable to. Questions run through a compiled pipeline that only calls a model when it has to, and every answer comes with its evidence.

      03 / EVALS

      Non-deterministic parts, deterministic checks

      A golden set of answerable and unanswerable questions runs in CI against the same pipeline, offline and for free. With a key it runs against Claude and reports real cost. The test suite fails if accuracy drops, a refusal breaks, or the cost gate starts letting most questions through to a model.

      04 / NOTES

      Engineering notes

      The decisions I would make again, and why. Most came from something going wrong first.

      01

      Every read and write is an event

      A hook appends each agent's brain access to an append-only activity.jsonl. The 3D brain, the session map and the audit are all views of that one log. Nothing is drawn that didn't happen.

      02

      Agents propose, a human approves

      Scheduled agents scan mail, chat and the brain itself, but they only write proposals. Anything live waits for an explicit yes. The pipeline agent here follows the same rule, enforced in code rather than in a prompt.

      03

      Say less than you verified

      "Verified" may only describe what was actually observed. In the pipeline this became the verifier: no citation, or a citation to a note that was never retrieved, means a refusal and not a guess.

      04

      Code that runs everywhere stays out of the sync

      The memory syncs through a shared company drive. Hook scripts run in every session, so they live outside it, where a synced file can't change what executes. No secrets ever enter the brain.

      05

      Measure on the machine that matters

      The first brain had over 650k triangles and stuttered on an integrated GPU. Profiling showed that full-screen transparent layers cost more than the geometry. The fix: clustered meshes, a painted sky and an adaptive quality ladder.

      06

      The eval found the bug I didn't

      Quoted evidence contained [[links]] from note footers, and the verifier read them as citations to notes that were never retrieved. It rejected correct answers. The golden set caught it at 71 %. The fix was in the store, not in the verifier.
