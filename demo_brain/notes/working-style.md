Answer first, in one sentence where possible. Report every finished task as a diff table against the plan, never just 'done'. Anything that changes a live system (website, ads, email) needs an explicit yes in chat first. Several open decisions are asked as one clickable questionnaire.

**Why:** keeps agents consistent across sessions.
**How to apply:** read before working in this area.
